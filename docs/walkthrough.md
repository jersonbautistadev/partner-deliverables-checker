## Full website script, after validation

**0:00 — The problem.** “While coordinating media partnerships for an event, publication instructions were scattered across conversations and documents. This tool makes approved instructions traceable and checks packages against them. All data in this demonstration is fictional.”

**0:30 — Overview.** Show upcoming Manila deadlines, incomplete packages and review items. Explain that deadline reminders do not prove external submission occurred. Open Campus Current's launch package.

**1:00 — Explain the report.** Show passed, failed, missing and needs-review findings. Follow one finding to its approved source and saved revision. Show why 1000 × 1000 fails an exact 1080 × 1080 rule.

**1:40 — Fix a package.** Upload a caption and a correct-size image. Observe new findings. Download the image through the protected route. Record an honest logo review with an explanation. The fictional seed poster has no logo and should fail visual inspection.

**2:20 — Change the instruction.** Revise a word limit with a change reason. Show the retained previous snapshot and refreshed report. Replace the image and show that a previous manual approval does not apply.

**3:00 — Show security.** Sign in as the other contributor and request the first contributor's package or download URL. Show the server denying access. Explain why hiding controls alone would not protect files.

**3:40 — Show engineering.** Run or show an actual green test/CI result. Explain engine/services/views separation, database transactions, private storage and one deployment decision. State the remaining limitations and actual pilot status.
